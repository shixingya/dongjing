# 动镜 DongJing

> 打开摄像头，AI 实时识别你的动作，在家、办公室就能即时健身，矫正体态。

纯网页 AI 体感私教：**13 个动作 · 33 关键点 · 26 条纠错规则 · 3 个体感关卡 · 7 天自动课表 · 8 项体态评估**，基于 MediaPipe Pose 在浏览器**本地实时推理**，画面不上传云端；
像 Posiqo 一样**只统计标准有效次数**，动作错了实时语音纠正；像慧动少年一样提供**两步（正面+侧面）体态快评**；像 BodyArcade 一样**把动作做成关卡**；还能**记住你的老毛病**、**每次自己复盘**。

## 功能（v3.3）

- 🎥 摄像头实时姿态识别（33 关键点骨骼叠加，镜像预览，全程本地运算）
- 🏋️ 十三个动作的有效次数引擎：力量系 **深蹲 / 开合跳 / 高抬腿 / 俯卧撑 / 弓步蹲 / 平板支撑 / 🧱靠墙静蹲**，坐姿上肢系（腿不入镜也能练）：**摇头放松 / 挥臂激活 / 🤸耸肩放松 / 🤲侧平举 / ✊手掌抓握（手指级，需 HandLandmarker）**，拉伸系：**🌗体侧伸展**
  - 每个动作都有可解释的判定标准（关节角度/摆动行程/指腕距离比/侧弯角度与停留时长），错误动作**不计入次数**
  - 实时纠错：HUD 横幅 + 中文语音（Web Speech）+ 合成音效（Web Audio，无外部音频文件）
- 📐 机位引导：正面/侧面摆放提示 + 起始姿势校准
- 🧍 两步体态快评（v1.7）：先**正面** 6 拍→ 头颈侧移 / 高低肩 / 骨盆侧倾 / 躯干侧偏；再提示你**转身 90°** 侧身 6 拍→ **头前倾 / 圆肩 / 骨盆前倾代偿 / 膝过伸**（矢状面，共 8 项）。输出体面评分 + 分级 + 方向文案（“耳在肩前方”）+ 拉伸建议，**两次以上自动画评分趋势折线**，报告页保留评估历史与最差一项；不愿配合转身可直接**“跳过侧面”**，退回只出正面 4 项（侧面位为单视角近似评估，不代替医生诊断）
- 📊 训练报告：本周柱状图、连续打卡、TOP 动作问题、历史记录（localStorage，无后端）
- 🎯 每日目标环（v1.1）：训练点进度环 + 达成语音庆祝，与连续打卡构成留存闭环（可在“我的”调节，0=关闭）
- ▶️ 组回放（v1.1）：训练结束后火柴人回放本组——录制的是本地关键点序列而非视频，1x/2x/0.5x 循环播放
- 🖼 分享成绩卡（v1.1）：canvas 生成 720×1080 海报（有效次数/评分/打卡天数/骨架装饰），一键保存或复制 PNG
- 🔁 循环跟练（v1.2）：首页"循环训练"自选 2–6 个动作（站/坐混选）各做 1 组，动作间自动休息 10 秒并引导重新摆姿势，整轮只扣 1 次额度，结果页聚合总览 + 整轮再来一遍
- 🧍‍♂️ 示范小人引导：机位/校准阶段画面中央常驻灰色小人（站姿 / 坐姿 / 侧面三套模板，带呼吸浮动），识别到真人后自动切换为加粗发光的绿色骨架跟随
- ✨ 一句话编排（v1.3）：不想自己选动作就说人话——“办公室久坐肩颈酸来 5 分钟”，自动排好动作顺序、算准时长与重复轮数，并告诉你它为什么这么排（Pro 动作自动避开）
- 🧠 教练记忆（v1.3）：从本机历史记录提炼你每个动作的老毛病，开练时语音提醒“我记得你上次膝盖内扣出现了 9 次”；首页“教练笔记”常驻输出近 14 天最常失分项与改进建议
- 📄 训练复盘（v1.3）：结果页自动生成四句复盘（数据→个人最佳对比→失分归因→下一步建议），可一键语音讲解，建议句还会印进分享海报
- 🎮 体感关卡（v1.4）：同一套姿态引擎直接玩，不额外下载模型——**⭐ 星星收集**（左右跨步接星，高星要举手过肩）、**⚡ 激光闪避**（身体待在哪一半就在哪一栏，跳栏 = 大幅跨步）、**🛡 深蹲护盾**（横梁压头前蹲下才挡得住）；60 秒一局、3 格血、难度逐档上升，得分与最高连击计入历史最佳并可分享成海报；**关卡不占用免费训练额度**
- 📅 本周课表（v1.6）：不再问“今天我该练什么”——首页直接排出周一起 7 天（下肢/肩颈/心肺/核心/久坐激活/关卡/休息），**按本机记录自动重算**：近两周哪个动作得分低就先排进来，Pro 动作只有订阅者能排，**免费额度排完后的训练日自动换成不扣额度的体感关卡**；点任意一天可预览详情与“为何这么排”，一个按钮直接开练（循环跟练 / 一局关卡），完成状态与每日目标同一口径
- 📱 移动端 / iOS Safari 专项（v1.5）：手机自动降到 640×480 + ~18fps 保续航；首次点击静默解锁语音（iOS 否则不肯发声）+ 长句心跳保活；切后台自动暂停识别、回前台自动接上，关页释放摄像头；竖屏改 3:4 画幅才容得下全身；微信内/`file://`/HTTP 打开时顶部直接给出处置指引，不让人对着黑屏猜
- 🧘 久坐与肩颈补齐（v1.8）：**侧平举**（双臂同时上下也不丢计数，上举全程弯肘超 45° 该次不计）、**体侧伸展**（肩髋连线侧弯 ≥14° 且停够 1 秒才计，刷两下不算）、**靠墙静蹲**（膝角 75–118° 且胸不往前塌才累计计时，对膝盖比深蹲友好）——三个动作全部走同一套 tracker 协议，免费/Pro 口径与课表、编排、循环跟练自动兼容；课表不再永远只排池首那几个老动作（**按周轮换**，弱项仍优先），一句话编排认识“膝盖不太行”——剔除跳跃与快频抬腿，把不磨膝的靠墙静蹲排第 1 位
- 📋 我的课程（v1.9）：循环跟练打完的结果页、或一句话编排的方案旁，都能一键“💾 存为常用课”——首页自动多出“我的课程”区，每张卡显示段数/预计时长/动作链，并标出“全程坐姿”“含 Pro”徽章，点“▶ 开练”直接重跑这套（含 Pro 动作时未订阅会先弹窗说明）；同组动作不论顺序都视为同一门课不会重复存，最多存 12 门，一张卡一键删除；均存于 localStorage，刷新不丢
- 💾 数据备份（v2.0）：本地无后端意味着清浏览器缓存 = 训练记录 / 体态评估 / 我的课程全丢且无法补救——“我的”页新增导出/导入：一键把本机数据导成一份 JSON（可存盘/换设备），导入时逐字段白名单校验、脏项丢弃，可选“整份覆盖”或“仅并训练记录”（同一次训练按时间+动作去重，重导不翻倍）；非动镜备份文件会被明确拒绝
- 🔥 训练热力图（v2.1）：报告页新增近 12 周 GitHub 风热力图，把每天训练点按日分桶染色（**与每日目标环完全同一口径**：计次 1 有效=1 点 / 计时每 10s=1 点 / 关卡得分÷3），设了每日目标就按目标 34%/67%/100% 分档、没设就用绝对档位；hover 任意格子看当天日期与训练点，配累计点数 / 活跃天数 / 连续打卡总览（分桶与等级全部走 exercises.js 纯函数 `buildHeatmap`，可离线单测）
- 🏅 成就徽章（v2.2）：报告页新增成就墙，9 枚里程碑（首次训练 / 尝鲜家 / 动作收藏家 / 七日之约 / 月度铁人 / 千点俱乐部 / 循环达人 / 玩家 / 体态初评），解锁的一排亮色带光框、未解锁的灰化并显真实进度条（如 5/5、24/30）；“练过的不同动作”只计真实动作库（关卡/循环不计），“连续打卡”今天未练会自动从昨天起算，训练点口径与目标环/热力图共用同一个 `recPoints`（全部 exercises.js 纯函数 `computeAchievements`，可离线单测）
- 📈 周环比小结（v2.3）：“本周训练”柱状图下方自动出一句本周 vs 上周的对比（本周 N 点 · 上周 M 点 + 结论），按周一起算同口径用 `recPoints` 比较训练点，涨则绿字“比上周多 X%”、跌则橙字“比上周少 X%…安排一次循环跟练补回来”、空缺则鼓/提醒破零（exercises.js 纯函数 `weekCompare`，可离线单测）

## 运行

在线试玩：**https://shixingya.github.io/dongjing/** （HTTPS，手机 Chrome 也能直接开摄像头）

浏览器在 `file://` 下禁用摄像头，请用以下任一方式启动（二选一）：

```bash
# 方式 1：在 dongjing 目录下起本地服务（PowerShell 用户直接执行第二行）
cd dongjing
python -m http.server 8790
# 打开 http://localhost:8790

# 方式 2：部署到 GitHub Pages / 任意 HTTPS 静态托管
```

首次打开需联网下载姿态模型（约 5MB，之后走浏览器缓存）。
推荐 Chrome/Edge 桌面端；手机用 Chrome（Android）或 Safari（iOS）直接打开上面的 HTTPS 链接即可，建议横屏放置、距离 1.5–2 米；**微信内链接打不开摄像头**，请点右上角「···」选择在系统浏览器中打开。
摄像头前 2-3 米，全身入镜。
