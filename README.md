# 动镜 DongJing

> 打开摄像头，AI 实时识别你的动作，在家、办公室就能即时健身，矫正体态。

纯网页 AI 体感私教：基于 MediaPipe Pose 的浏览器**本地实时推理**，画面不上传云端；
像 Posiqo 一样**只统计标准有效次数**，动作错了实时语音纠正；像慧动少年一样提供**30 秒体态快评**。

## 功能（v1.2）

- 🎥 摄像头实时姿态识别（33 关键点骨骼叠加，镜像预览，全程本地运算）
- 🏋️ 十个动作的有效次数引擎：**深蹲 / 开合跳 / 高抬腿 / 俯卧撑 / 弓步蹲 / 平板支撑**，另加坐姿上肢系（腿不入镜也能练）：**摇头放松 / 挥臂激活 / 🤸耸肩放松 / ✊手掌抓握（手指级，需 HandLandmarker）**
  - 每个动作都有可解释的判定标准（关节角度/摆动行程/指腕距离比），错误动作**不计入次数**
  - 实时纠错：HUD 横幅 + 中文语音（Web Speech）+ 合成音效（Web Audio，无外部音频文件）
- 📐 机位引导：正面/侧面摆放提示 + 起始姿势校准
- 🧍 体态快评：头颈侧移 / 高低肩 / 骨盆侧倾 / 躯干侧偏 + 体面评分与拉伸建议
- 📊 训练报告：本周柱状图、连续打卡、TOP 动作问题、历史记录（localStorage，无后端）
- 🎯 每日目标环（v1.1）：训练点进度环 + 达成语音庆祝，与连续打卡构成留存闭环（可在“我的”调节，0=关闭）
- ▶️ 组回放（v1.1）：训练结束后火柴人回放本组——录制的是本地关键点序列而非视频，1x/2x/0.5x 循环播放
- 🖼 分享成绩卡（v1.1）：canvas 生成 720×1080 海报（有效次数/评分/打卡天数/骨架装饰），一键保存或复制 PNG
- 🔁 循环跟练（v1.2）：首页"循环训练"自选 2–6 个动作（站/坐混选）各做 1 组，动作间自动休息 10 秒并引导重新摆姿势，整轮只扣 1 次额度，结果页聚合总览 + 整轮再来一遍
- 💎 商业占位：免费 = 6 个基础动作（含坐姿摇头/挥臂/耸肩）+ 每月 6 次；Pro ¥29/月 · ¥168/年含手指级抓握（演示开关本地激活，支付通道 P1 接入）

## 运行

在线试玩：**https://shixingya.github.io/dongjing/** （HTTPS，手机 Chrome 也能直接开摄像头）

浏览器在 `file://` 下禁用摄像头，请用以下任一方式启动（二选一）：

```bash
# 方式 1：在 dongjing 目录下起本地服务（PowerShell 用户直接执行第二行）
cd dongjing
python -m http.server 8790
# 打开 http://localhost:8790

# 方式 2：部署到 GitHub Pages / 任意 HTTPS 静态托管
```

首次打开需联网下载姿态模型（约 5MB，之后走浏览器缓存）。
推荐 Chrome/Edge 桌面端；摄像头前 2-3 米，全身入镜。
